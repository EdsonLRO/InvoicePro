# Tallyo public assets

This directory contains the current approved brand and promotional assets.

- `advertising/`: the 14-image campaign for the updated Tallyo app.
- `social/`: X profile images and the informative X header.
- `product/`: current fictional-data product captures used by the public website and advertising renderer.
- `email/`: current product images used by the optional Tallyo overview email.
- Root image files: the active Tallyo mark, wordmark, favicon and website social card.

The retired `App Screenshots/` collection was removed. Do not restore it or use screenshots containing real customer, account, payment or provider data.
