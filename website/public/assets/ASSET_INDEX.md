# Tallyo asset library

This folder is the canonical library for public Tallyo brand, product and
campaign imagery. Use the descriptive filenames below instead of copying an
image into a new location.

## Brand

- `tallyo-mark.png` - official Tallyo mark for light backgrounds.
- `tallyo-wordmark-white.png` - official horizontal white wordmark for dark
  backgrounds.
- `icon-192.png` - square application icon.
- `tallyo-social-card.webp` - default website sharing image.
- `social/linkedin/profile-picture.png` - LinkedIn profile image.
- `social/linkedin/cover-1128x191.png` and
  `social/linkedin/cover-4200x700.png` - LinkedIn cover variants.

Do not redraw, retype or use an AI-generated approximation of the logo.

## Naming and replacement rules

1. Use lowercase kebab-case filenames.
2. Include a platform or purpose folder instead of platform names in every
   filename.
3. Use fictional sample data and never expose real customer or account data.
4. Replace an image only after confirming that it shows the current app and
   official logo.
5. Update this index whenever a reusable asset is added, replaced or removed.
